# Smart Study Planner & Performance Predictor
This project is an AI/ML-based system designed to predict student performance based on study habits and generate personalized study plans.
## Features
- Data collection using Google Forms
- Data preprocessing using Python (Pandas)
- Machine learning model (in progress)
- Personalized study recommendations
## Tech Stack
- Python
- Pandas
- Scikit-learn
## Status
Project is currently in progress.
