# Smart Study Planner & Performance Predictor

## 📌 Project Overview

Smart Study Planner & Performance Predictor is an AI/ML-based project developed to predict student academic performance based on study habits, attendance, sleep schedule, stress level, and social media usage.
The system also provides personalized study recommendations according to the predicted performance category.

---

## 🎯 Objectives

- Predict student performance using machine learning
- Analyze factors affecting academic results
- Provide personalized study plans
- Help students improve productivity and exam preparation

---

## 📊 Dataset Details

The dataset was collected using Google Forms from students.

### Features Used:

- Age
- Gender
- Year
- Average Study Hours per Day
- Attendance Percentage
- Previous Exam Percentage
- Average Sleep Hours per Day
- Daily Social Media Usage
- Stress During Exams
- Subject Difficulty Rating

### Target Variable:

- Most Recent Exam Percentage


## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 🤖 Machine Learning Algorithm

- Random Forest Classifier

Random Forest was used because it provides good accuracy and handles mixed data efficiently.

## ⚙️ Project Workflow

1. Data Collection using Google Forms

8. Personalized Study Recommendation
